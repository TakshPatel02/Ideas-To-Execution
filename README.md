# Ideas to Execution – Interactive Storytelling

An immersive scroll-based storytelling experience that explores the journey from ideas to execution. Built with React, GSAP, and Tailwind CSS, this project demonstrates how purposeful animation and interaction can communicate powerful narratives about product development and design philosophy.

## ✨ Features

- **Scroll-triggered Animations**: Smooth, purposeful animations that reveal content as you scroll
- **Responsive Design**: Optimized for all screen sizes
- **Performance Optimized**: Built with Vite for fast development and production builds
- **Modern Stack**: React 19, GSAP 3, Tailwind CSS 4

## 🚀 Demo

Experience the journey from confusion to clarity, exploring how ideas survive through proper execution.

## 🛠️ Tech Stack

- **React 19** - UI framework
- **GSAP 3.14** - Animation library with ScrollTrigger
- **Tailwind CSS 4** - Utility-first CSS framework
- **Vite** - Build tool and dev server

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/ideas-to-execution.git

# Navigate to the project directory
cd ideas-to-execution

# Install dependencies
npm install

# Start the development server
npm run dev
```

All animations are carefully timed and choreographed using GSAP's ScrollTrigger plugin, creating a seamless narrative flow that responds to user scroll behavior.
